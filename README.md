# CS2 Skin Price Bot 🔫💸

Telegram-бот, который по названию скина CS2 ищет минимальную цену сразу на
нескольких торговых площадках и присылает сводку, отсортированную от дешёвых
к дорогим.

## Площадки

| Ключ         | Площадка       | Ключ? | Как получает цену                                   |
|--------------|----------------|-------|-----------------------------------------------------|
| `lisskins`   | LisSkins       | нет   | публичный JSON-фид прайса (кэш)                      |
| `skinport`   | Skinport       | нет   | публичный `/v1/items` — весь прайс-лист (кэш)        |
| `steam`      | Steam Market   | нет   | `priceoverview` API (опорная цена)                  |
| `csfloat`    | CSFloat        | **да**| `/api/v1/listings`; нужен `CSFLOAT_API_KEY`          |
| `csmoney`    | CS.Money       | —     | за Cloudflare, нестабильно (см. ниже)               |
| `aimmarket`  | AIM Market     | —     | за Cloudflare, нестабильно (см. ниже)               |

По умолчанию включены только надёжные бесключевые площадки:
`lisskins, skinport, steam`. Каждая площадка изолирована: если одна недоступна
или сменила формат ответа — бот всё равно покажет цены с остальных, а рядом
отметит, где не нашлось.

### CSFloat (опционально)

CSFloat отдаёт листинги только с API-ключом. Возьмите бесплатный ключ в профиле
на csfloat.com, положите его в `CSFLOAT_API_KEY` и добавьте `csfloat` в
`ENABLED_PROVIDERS`.

### CS.Money и AIM Market

Обе площадки закрыты Cloudflare, а их внутренние API меняются и требуют
браузерных заголовков/куки — надёжно тянуть их простым ботом нельзя, поэтому по
умолчанию они выключены (код провайдеров оставлен в `providers/` для желающих
поэкспериментировать или подключить через агрегатор с ключом, например
Pricempire).

## Установка

```bash
git clone <repo>
cd cs-skins-
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка

1. Получите токен бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `.env.example` в `.env` и впишите токен:

```bash
cp .env.example .env
# отредактируйте TELEGRAM_TOKEN=...
```

Переменные окружения:

| Переменная          | Назначение                                                  |
|---------------------|-------------------------------------------------------------|
| `TELEGRAM_TOKEN`    | токен бота (обязательно)                                     |
| `ENABLED_PROVIDERS` | список площадок через запятую; пусто = все                   |
| `REQUEST_TIMEOUT`   | таймаут запроса к площадкам в секундах (по умолчанию 30)     |

## Запуск

```bash
python bot.py
```

## Использование

- Пришлите боту название скина текстом — **по-русски или по-английски**:
  `ак редлайн`, `AK-47 Redline`, `AWP Asiimov`, `нож керамбит fade`.
- Если вариантов несколько — бот покажет **кнопки выбора скина**, затем
  **кнопки выбора износа** (FN/MW/FT/WW/BS) и только потом ищет цены.
- Износ можно указать сразу словом/сокращением: `калаш редлайн бс`,
  `AWP Asiimov FT` — тогда шаг выбора износа пропускается.
- Или командой: `/price AWP | Asiimov (Field-Tested)`.
- `/start`, `/help` — справка.

### Ввод на русском

Поддерживаются:
- русские/разговорные названия оружия (`калаш`, `авп`, `дигл`, `глок`…);
- популярные названия скинов (`редлайн`, `азимов`, `вулкан`, `фейд`, `доплер`…);
- износы словом или сокращением (`прямо с завода`/`фн`/`fn`,
  `после полевых`/`фт`/`ft`, `закалённое в боях`/`бс`/`bs` и т.д.);
- остальная кириллица транслитерируется автоматически.

Словари синонимов лежат в `translit.py` и легко расширяются — добавьте пару
`алиас -> английское_название`.

## Архитектура

```
bot.py               — обработчики Telegram, кнопки выбора скина/износа, вывод
config.py            — чтение настроек из окружения / .env
catalog.py           — общий каталог из фида LisSkins (цены + список скинов/износов)
skinutils.py         — нормализация имён, разбор износа, константы
translit.py          — перевод запроса RU/EN + транслитерация
providers/
  base.py            — базовый класс BaseProvider и модель PriceResult
  lisskins.py        — LisSkins (берёт цены из общего каталога)
  csmoney.py         — CS.Money
  aimmarket.py       — AIM Market
  steam.py           — Steam Market
  __init__.py        — реестр провайдеров + build_providers()
```

### Как работает выбор

Фид LisSkins содержит весь каталог предметов, поэтому по нему строятся:
списки скинов (для кнопок выбора) и доступные износы каждого скина. Тот же
каталог используется как источник цены LisSkins — фид скачивается один раз и
кэшируется на 5 минут.

### Добавить новую площадку

1. Создайте `providers/mymarket.py` с классом-наследником `BaseProvider` и
   методом `async def search(self, client, query) -> PriceResult`.
2. Зарегистрируйте его в `ALL_PROVIDERS` в `providers/__init__.py`.
3. Добавьте ключ в `ENABLED_PROVIDERS` при необходимости.

## Важно про эндпоинты

LisSkins, CS.Money и AIM Market не всегда публикуют стабильный официальный API,
и адреса/форматы их эндпоинтов иногда меняются. Парсинг сделан «терпимым» и
изолированным, но если конкретная площадка вдруг перестала отдавать цены —
достаточно поправить `API_URL`/`_parse()` в её модуле, не трогая остальной бот.
Для площадок с официальным API (по токену) добавьте заголовок авторизации в
`search()` соответствующего провайдера.

Бот только читает публичные цены и не совершает покупок.

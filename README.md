# CS2 Skin Price Bot 🔫💸

Telegram-бот, который по названию скина CS2 ищет минимальную цену сразу на
нескольких торговых площадках и присылает сводку, отсортированную от дешёвых
к дорогим.

## Площадки

| Ключ         | Площадка       | Как получает цену                                   |
|--------------|----------------|-----------------------------------------------------|
| `lisskins`   | LisSkins       | публичный JSON-фид прайса (кэшируется на 5 минут)    |
| `csmoney`    | CS.Money       | market-эндпоинт лотов продажи                        |
| `aimmarket`  | AIM Market     | внутренний market-эндпоинт поиска                    |
| `steam`      | Steam Market   | `priceoverview` API (опорная цена)                  |

Каждая площадка изолирована: если одна недоступна или сменила формат ответа —
бот всё равно покажет цены с остальных, а рядом отметит, где не нашлось.

## Установка

```bash
git clone <repo>
cd cs-skins-
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка

1. Получите токен бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `.env.example` в `.env` и впишите токен:

```bash
cp .env.example .env
# отредактируйте TELEGRAM_TOKEN=...
```

Переменные окружения:

| Переменная          | Назначение                                                  |
|---------------------|-------------------------------------------------------------|
| `TELEGRAM_TOKEN`    | токен бота (обязательно)                                     |
| `ENABLED_PROVIDERS` | список площадок через запятую; пусто = все                   |
| `REQUEST_TIMEOUT`   | таймаут запроса к площадкам в секундах (по умолчанию 30)     |

## Запуск

```bash
python bot.py
```

## Использование

- Пришлите боту название скина текстом:
  `AK-47 | Redline (Field-Tested)`
- Или командой: `/price AWP | Asiimov (Field-Tested)`
- `/start`, `/help` — справка.

Точнее всего работает полное название со стиранием (например
`M4A4 | Howl (Minimal Wear)`), но бот умеет и нечёткий поиск по токенам
(`ak redline field` тоже найдётся).

## Архитектура

```
bot.py               — обработчики Telegram, параллельный опрос площадок, вывод
config.py            — чтение настроек из окружения / .env
providers/
  base.py            — базовый класс BaseProvider и модель PriceResult
  lisskins.py        — LisSkins (кэш фида)
  csmoney.py         — CS.Money
  aimmarket.py       — AIM Market
  steam.py           — Steam Market
  __init__.py        — реестр провайдеров + build_providers()
```

### Добавить новую площадку

1. Создайте `providers/mymarket.py` с классом-наследником `BaseProvider` и
   методом `async def search(self, client, query) -> PriceResult`.
2. Зарегистрируйте его в `ALL_PROVIDERS` в `providers/__init__.py`.
3. Добавьте ключ в `ENABLED_PROVIDERS` при необходимости.

## Важно про эндпоинты

LisSkins, CS.Money и AIM Market не всегда публикуют стабильный официальный API,
и адреса/форматы их эндпоинтов иногда меняются. Парсинг сделан «терпимым» и
изолированным, но если конкретная площадка вдруг перестала отдавать цены —
достаточно поправить `API_URL`/`_parse()` в её модуле, не трогая остальной бот.
Для площадок с официальным API (по токену) добавьте заголовок авторизации в
`search()` соответствующего провайдера.

Бот только читает публичные цены и не совершает покупок.
